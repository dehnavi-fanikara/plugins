# پلاگین محاسبه قیمت لوله‌بازکنی فانیکارا

این پلاگین یک ابزار محاسبه حدود قیمت خدمات لوله‌بازکنی را در وردپرس نمایش می‌دهد. محاسبه قیمت به‌صورت لحظه‌ای و بدون دکمه محاسبه انجام می‌شود.

## نصب

1. پوشه `fanikara-calc-pricing` را در مسیر زیر قرار دهید:

   `wp-content/plugins/`

2. از بخش «افزونه‌ها» در پیشخوان وردپرس، پلاگین «Fanikara Pipe Opening Price Calculator» را فعال کنید.
3. در یک برگه یا نوشته، شورت‌کد زیر را قرار دهید:

   ```text
   [fanikara_price_calculator]
   ```

شورت‌کد جایگزین زیر نیز پشتیبانی می‌شود:

```text
[fcp_price_calculator]
```

## تنظیم قیمت‌ها

پس از فعال‌سازی، از مسیر زیر می‌توانید مقادیر ثابت فرمول را تغییر دهید:

`پیشخوان وردپرس ← تنظیمات ← قیمت‌گذاری لوله‌بازکنی`

موارد قابل تنظیم:

- متن خروجی هزینه بنایی
- متن خروجی هزینه توافقی
- هزینه فنر به‌ازای هر متر
- هزینه هر دقیقه خدمت برای هر نفر
- ضریب روز عادی / ساعات عادی
- ضریب روز عادی / سرویس شبانه
- ضریب روز تعطیل / ساعات عادی
- ضریب روز تعطیل / سرویس شبانه
- نرخ مالیات بر ارزش افزوده

### رنگ‌بندی

رنگ‌بندی ابزار نیز از همان صفحه تنظیمات قابل تغییر است. مقدارهای پیش‌فرض فعلی:

- رنگ پایه: `#f9fafb`
- رنگ hover و حالت فعال: `#FE7F2E`
- رنگ بخش قیمت: `#166534`

همچنین رنگ پس‌زمینه کارت، متن‌ها، برچسب‌ها، توضیحات، بوردرها، هشدارها و حالت موفقیت قابل تنظیم هستند. این تغییرات فقط روی محاسبه‌گر اعمال می‌شوند و رنگ قالب وردپرس را تغییر نمی‌دهند.

مبالغ در تنظیمات بر اساس تومان وارد می‌شوند.

## منطق محاسبه

منطق محاسبه بر اساس فایل مرجع `drain-price-calculator-formula-v5.html` و شبه‌کد `Final Price Calculation.js` پیاده‌سازی شده است.

### هزینه بنایی

اگر نوع خدمت «بنایی و کنده‌کاری» باشد، متن هزینه بنایی نمایش داده می‌شود و محاسبه عددی انجام نمی‌شود.

### هزینه توافقی

اگر یکی از شرایط زیر برقرار باشد، متن هزینه توافقی نمایش داده می‌شود:

- تجهیزات استفاده‌شده فنر معمولی نباشد.
- متراژ فنر بیشتر از ۵ متر باشد.
- نوع خدمت «سایر» باشد.
- علت مشکل نه گرفتگی با مدفوع باشد و نه گرفتگی به دلیل اجسام غیرسخت.

### محاسبه عددی

در حالت عادی، فرمول به این ترتیب اجرا می‌شود:

```text
final_price_min = ((spring_diameter - 2) / 10)
                  × spring_cost_per_meter
                  × spring_length

final_price_min += service_cost_per_minute_per_person × service_duration
final_price_min *= service_time
final_price_min *= technician_count
final_price_min += transportation_cost
final_price_min += equipment_rental_cost
final_price_min += equipment_transport_cost
final_price_min *= tax_multiplier
final_price_min += tip

final_price_max = final_price_min × 1.25
```

خروجی نهایی به شکل زیر نمایش داده می‌شود:

```text
حدودا بین حداقل قیمت تا حداکثر قیمت تومان
```

## فیلدهای فرم

فرم شامل شهر، نوع خدمت، متراژ فنر، قطر فنر، مدت زمان خدمت، علت مشکل، زمان ارائه خدمات، تعداد فنی‌کار، فاکتور معتبر و موارد خاص است.

موارد خاص شامل فاکتور رسمی با ارزش افزوده، خارج از شهر، هزینه ایاب‌وذهاب، انعام، تجهیزات استفاده‌شده، اجاره تجهیزات و کرایه حمل تجهیزات است.

فیلدهای عددی فقط رقم می‌پذیرند. اعداد فارسی و عربی هنگام ورود به اعداد انگلیسی تبدیل می‌شوند و سایر کاراکترهای غیرعددی حذف می‌شوند.

## نکات فنی

- دارایی‌های CSS و JavaScript فقط زمانی بارگذاری می‌شوند که شورت‌کد در صفحه وجود داشته باشد.
- خروجی راست‌به‌چپ و واکنش‌گرا است.
- آیکون‌های فرم به‌صورت SVG داخل خروجی پلاگین قرار گرفته‌اند.
- فرمول در JavaScript اجرا می‌شود تا قیمت بدون ارسال درخواست و به‌صورت لحظه‌ای تغییر کند.
- به همین دلیل، مقادیر تنظیم‌شده برای محاسبه به مرورگر ارسال می‌شوند و برای مخفی‌سازی منطق محاسبه باید محاسبه به PHP/AJAX منتقل شود.
